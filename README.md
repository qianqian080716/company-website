# 公司品牌官网（中 / 英 / 阿拉伯语）

单文件静态网站：`index.html`。不需要数据库或后端，直接上传到任何服务器（Nginx、Apache、宝塔、GitHub Pages 等）即可访问。

## 如何替换占位内容

打开 `index.html`，滚动到底部的 `<script>` 部分，只需要改三处：

1. **① CONFIG（公司信息）**
   - `whatsapp`：WhatsApp 号码，格式为国家码+号码，不带 `+` 和空格，例如 `971501234567`
   - `whatsappDisplay` / `phones`（可填多个）/ `email`：页面上显示的联系方式
   - `mapQuery`：地图位置，可填地址或经纬度，例如 `"25.2048,55.2708"`

2. **② PRODUCTS（商品）**：按示例格式增删商品，每个商品填写中/英/阿三种语言的名称和规格、起订量 `moq`、类别 `cat`。要显示商品图片，把图片放进 `images/` 文件夹，并加上 `img:"images/文件名.jpg"`。`CATEGORIES` 里可以修改商品类别名称。

3. **③ T（三语文案）**：所有方括号 `[ ]` 里的内容都是占位文字，请替换为真实内容。`brand.mark` 是左上角的字母标志，可以改成公司首字母。

首页的统计数字（10+、500+ 等）在 HTML 的 `stats` 区块里直接修改。

## 语言

- 右上角切换中文 / EN / العربية，阿拉伯语自动切换为从右到左排版
- 可以用链接直接指定语言：`?lang=zh`、`?lang=en`、`?lang=ar`
- 首次访问会按访客浏览器语言自动选择

## WhatsApp

所有 WhatsApp 按钮都会打开与你号码的对话，并预填一句询价话术（随语言变化）；商品卡片上的“询价”按钮会自动带上商品名称。
